## One-liner (SSOT)

> Elynd is an English **learning space** for adults who struggle to persist: interesting, mostly understandable real content (read + listen), with tools—including AI—that lower friction. Not a course, vocab pack, or chatbot.

Any README, rule, or marketing blurb should match this—not invent a parallel identity.
