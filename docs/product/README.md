## One-liner (SSOT)

> Elynd is an **AI Native Language Reading Environment**. It helps people read authentic English the way they use a modern ebook reader, with contextual AI help when meaning breaks down. Not a course, not drills, not a chatbot. The core is helping people keep reading English they actually want to read.

Any README, rule, or marketing blurb should match this—not invent a parallel identity.
